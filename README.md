# Ecuity Exousia Landing Page
A static landing page for a Hyderabad-based client, built with React and Material UI.

## Features
- Responsive design
- Clean UI with Material UI components
- Optimized for performance

## Live Demo
[ecuityexousia.in](https://www.ecuityexousia.in)

## How to Run
1. Clone: `git clone https://github.com/Sanath2349/ecuityexousia.git`
2. Install: `npm install`
3. Start: `npm start`
